마케팅 AI 에이전트
전체 그림과 한계

측정(눈)과 위법 차단(브레이크)은 만들어 돌아갑니다. 아래는 전체 파이프라인에서 지금 되는 것, 중요하지만 남은 것, 그리고 정직하게 AI가 못하는 것입니다.

02

중요도 × 상태 — 무엇이 급한가

중요도가 높은데 아직 안 된 것 = 다음 우선순위. 왼쪽 색 막대가 상태입니다.

컴플라이언스 게이트

중요도 ★★★

위법 표현 차단 + 대체문구 제안. 안 지키면 병원이 처벌받는 최우선 안전장치.

✅ 완성·작동

일일 순위 트래커

중요도 ★★☆

매일 키워드 순위 측정·추세·알림. 루프의 눈. 공식 API 기반(크롤링 아님).

✅ 완성·작동

전환(예약전화) 측정

중요도 ★★★

진짜 성과 지표. 순위가 아니라 예약으로 이어졌는지. 외부 데이터 연동 필요.

⚪ 미착수

평가 3중 루프

중요도 ★★☆

콘텐츠/채널/전략을 주기별로 판정. 설계서엔 있지만 코드로는 미구현.

◐ 설계만

콘텐츠 생성기

중요도 ★★☆

페르소나·구조 규격에 맞춰 실제 초안 작성. 게이트와 자동 연결 예정(손).

⚪ 미착수

키워드 발굴 엔진

중요도 ★☆☆

검색량·경쟁·전환의도로 롱테일 우선순위 산출. 지금은 수동 목록.

⚪ 미착수
03

못하는 것 — AI의 한계 (정직하게)

이걸 알고 시작해야 사고가 안 납니다. 오른쪽은 "그럼 어떻게 메우나"입니다.

⛔ 이 에이전트가 스스로 할 수 없는 것

자동화해도 남는 7가지. 대부분 "사람" 또는 "외부 연동"으로만 메울 수 있습니다.

  • 1

    정확한 실제 검색순위(SERP)

    공식 API는 실제 통합검색 순위와 근사할 뿐, 완전히 같지 않음. 지역·로그인·시점마다 달라짐.

    → 대응: 추세(7일 이동평균)로 판단. 정확도 필요 시 유료 순위추적 SaaS로 교체.

  • 2

    법적 최종 판단

    컴플라이언스 게이트는 1차 필터. "위법 아님"을 보증하지 못함.

    → 대응: 의료광고 사전심의 · 의료인 감수는 사람이 필수. AI는 후보만 걸러줌.

  • 3

    원내 실제 사진·동영상 촬영

    상위노출에 필요한 직접 촬영 이미지(6~13장)·모먼트는 AI가 못 찍음.

    → 대응: 병원에서 촬영·제공. AI는 환자 식별정보 마스킹 검증만.

  • 4

    진짜 체류시간·예약 전환 측정

    블로그 체류시간·전화예약 데이터는 에이전트 안에 없음. 이게 없으면 "진짜 성과"를 모름.

    → 대응: 네이버 애널리틱스·통화추적 연동 필요(외부 데이터).

  • 5

    인과관계 자동 증명

    "순위가 올랐다 = 우리 전략 덕분"이라고 AI 혼자 단정 못함. 계절·경쟁·네이버 업데이트가 섞임.

    → 대응: A/B·홀드아웃 실험 설계 없이는 "효과 있음" 판정 불가.

  • 6

    100% 무인 자동발행

    의료 도메인은 완전 자동 발행이 위험. 오판 시 병원 책임.

    → 대응: 사람 승인(HITL)이 들어간 반자동이 정답.

  • 7

    네이버 알고리즘 변경 예측

    네이버가 로직을 언제 어떻게 바꿀지 미리 알 수 없음. 목적함수가 흔들릴 수 있음.

    → 대응: 변화점 탐지 후 사람이 재설계. 예측이 아니라 대응.
