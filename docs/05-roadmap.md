# 05. 개발 로드맵 & 기술 스택

## 1. 단계별 로드맵

핵심 원칙: **매칭이 되어야 나머지 기능이 의미 있다.** 초기에는 유동성 확보와 매칭 성사에 모든 자원을 집중하고, 서류·업체·결제는 수동 운영(Concierge MVP)으로 검증 후 자동화한다.

### Phase 0 — 검증 (4주)

| 항목 | 내용 |
|---|---|
| 목표 | 타깃 단지 1곳 선정 + 수요 검증 |
| 산출물 | 랜딩 페이지(사전등록), 단지 선정 리포트, 협력 중개사 1곳 MOU |
| 성공 기준 | 사전등록 100세대 (단지의 5%+) |
| 검증 방법 | 사전등록 시 희망 조건까지 받아서 **수동으로 사이클 존재 여부 확인** |

### Phase 1 — MVP: 매칭 성사 (8~10주)

| 기능 | 범위 |
|---|---|
| 회원/인증 (기능1) | 본인인증 + 소유주 인증(수동 심사 우선, 자동화 후순위), 프로필·선호 등록 |
| 매칭 (기능2) | 배치 매칭 v1: 하드 필터 + 가중치 + **2/3-사이클 열거** (TTC full 구현은 v2) |
| CRM (기능6) | 최소 기능: 고객 목록, 딜 파이프라인 보드, 상담 메모 |
| 매칭 이후 | **전부 수동 운영**: 운영자가 중개사 연결, 서류 안내, 일정 조율 |

**성공 기준: 순환거래 1건 성사** (2자 맞교환이라도). 이것이 전체 사업의 존재 증명.

### Phase 2 — 거래 자동화 (10~12주)

| 기능 | 범위 |
|---|---|
| 매칭 v2 | TTC 정식 구현 + ILP 사이클 최적화, 체인 매칭(순수 매도/매수자), 실시간 2-사이클 알림 |
| 서류 (기능3) | 카카오톡 전자증명서 연동, 거래 단계별 체크리스트 |
| 세금 계산기 (기능5) | 양도세·취득세·보유세 + 갈아타기 통합 시뮬레이션 |
| 소유주 인증 자동화 | 등기부 조회 연동 |

### Phase 3 — 생태계 & 수익화 (12주+)

| 기능 | 범위 |
|---|---|
| 협력업체 (기능4) | 이사·법무 견적 시스템, 연쇄 이사 시간표 |
| 결제 (기능7) | PG 연동, 성사 수수료, 현금영수증/세금계산서 자동 발행 |
| 보고서 (기능8) | 거래 보고서 PDF 자동 생성, 운영 대시보드 |
| 확장 | 인접 단지 추가, 프리미엄 멤버십 |

## 2. 기술 스택 (제안)

| 레이어 | 선택 | 이유 |
|---|---|---|
| 프론트엔드 | Next.js (React) + TypeScript | 모바일웹 우선, SEO(단지 페이지), 추후 앱은 웹뷰/RN |
| 백엔드 API | NestJS (TypeScript) | 프론트와 언어 통일, 구조화된 모듈 |
| 매칭 엔진 | Python (NetworkX → OR-Tools) | 그래프/최적화 생태계, 워커로 분리 |
| DB | PostgreSQL | JSONB(선호·점수), 배열 타입, 트랜잭션 |
| 큐/캐시 | Redis + BullMQ | 배치 매칭 잡, 알림 큐 |
| 인증 | 카카오 로그인 + PASS 본인인증 | 타깃 유저 친화 |
| 알림 | 카카오 알림톡 + 푸시 | 매칭 제안 48시간 응답 유도 |
| 인프라 | AWS (ECS/RDS/S3) 또는 Vercel+Supabase(초기) | 초기 비용 최소화 |
| 문서 생성 | PDF 렌더러 (Playwright print) | 거래 보고서 |

## 3. 핵심 리스크 & 대응

| 리스크 | 심각도 | 대응 |
|---|---|---|
| **초기 유동성 부족** (매칭 상대 없음) | ★★★ | 단지 1곳 집중, 사전등록으로 풀 확보 후 오픈, 편도 수요도 흡수 |
| **사이클 파기** (1명 변심 → 전체 무산) | ★★★ | 사이클 길이 ≤3, 가계약금 동시 교환 구조, 이탈 페널티 정책 |
| **중개사법 저촉** (무등록 중개 행위) | ★★★ | 법률 자문 선행, 계약은 협력 중개사 수행, 플랫폼은 정보제공 포지션 명확화 |
| 동시 잔금 실행 실패 | ★★ | 법무법인 일괄 수임, 동시이행 각서, 에스크로 검토 |
| 세금 계산 오류 책임 | ★★ | 모의계산 면책 고지, 세무사 검수, 세율표 버전 관리 |
| 시장 침체로 갈아타기 수요 감소 | ★★ | 맞교환(2-사이클)은 시세와 무관하게 수요 존재 — 코어 유지 |
| 개인정보/서류 유출 | ★★ | 암호화 보관, 거래 후 자동 파기, 최소 수집 |

## 4. 성공 지표 (KPI)

| 단계 | 북극성 지표 | 보조 지표 |
|---|---|---|
| Phase 0 | 사전등록 세대수 | 등록 전환율, 조건 입력 완성률 |
| Phase 1 | **순환거래 성사 건수** | 매칭 제안 수락률, 프로필 완성률, 잠재 사이클 수 |
| Phase 2 | 월 성사 건수, 리드타임(가입→잔금) | 배치당 사이클 발견 수, 48h 응답률 |
| Phase 3 | 거래당 수익(ARPU), 협력업체 부착률 | 수수료 결제 전환율, NPS |
