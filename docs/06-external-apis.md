## 1. 등기부등본 & 소유주 검증 (기능 1 핵심)

### 1-1. 공식 경로의 한계

- **대법원 인터넷등기소(IROS)**: 개별 부동산 등기부 열람·발급을 위한 **공식 대외 Open API를 제공하지 않는다.** 사람이 웹사이트에서 열람(700원)/발급(1,000원)하는 구조.
- **[등기정보광장 Open API](https://data.iros.go.kr/rp/oa/openOapiIntro.do)**: 등기 신청 **통계·현황 데이터**만 제공 (소유권이전 건수 등). 개별 물건의 소유자 정보는 없음. 인증키 유효기간 24개월. → 시장 분석용으로는 유용, 소유주 인증용으로는 불가.

### 1-2. 현실적 선택지 — 스크래핑 대행 API (애그리게이터)

이용기관(우리)이 API 이용료 + 등기소 실비를 부담하고, 대행사가 인터넷등기소를 자동 조회해 구조화된 JSON으로 반환하는 방식. 업계 표준 관행.

| 업체 | 상품 | 특징 |
|---|---|---|
| **[CODEF](https://developer.codef.io/products/public/each/ck/real-estate-register)** | 인터넷등기소 부동산등기부등본 열람/발급 API | 개발자 문서 충실, 스타트업 채택 다수. 열람 결과를 항목별 파싱(소유자 성명·생년·주소, 근저당 등) 제공 |
| **[하이픈(Hyphen)](https://hyphen.im/product/view?seq=47)** | 부동산 종합정보(인터넷등기소) | **"등기부등본 소유자 검증"** 상품 별도 제공 — 이름+생년월일 대조 결과만 받는 형태라 우리 유스케이스에 최적 |
| **[Tilko](https://tilko.net/Support/Notice/55)** | 대법원 인터넷등기소 API | 정부24·홈택스 등 타 기관 API와 한 계약으로 묶기 좋음 |
| [에이픽(APick)](https://apick.app/dev_guide/iros1) | 부동산등기부등본 열람 API | 소형, 단가 저렴한 편 |

**소유주 인증 로직 (제안):**

```
회원이 단지·동·호수 입력
→ 주소를 고유번호(부동산 식별)로 변환 (대행 API의 주소검색 엔드포인트)
→ 등기부 열람 API 호출 (건당 실비 700원 + API 수수료)
→ 갑구 최종 소유자 [성명 + 생년월일(주민번호 앞자리)] 추출
→ 본인확인(1-3절) 결과의 [성명 + 생년월일]과 자동 대조
→ 일치: 인증 완료 / 불일치·공동명의: 수동 심사 큐로
```

**주의사항:**
- 등기부에는 주민번호 뒷자리가 마스킹되어 있음 → 성명+생년월일 대조가 실무 한계선. 동명이인 리스크는 "매칭 확정 직전 재열람 + 계약 단계 신분증 대면 확인"으로 이중 방어.
- 스크래핑 기반이라 등기소 점검시간(새벽) 호출 불가 — 야간 배치 설계 시 고려.
- 비용 설계: 인증 1회당 약 1,000~1,500원(실비+수수료) → 가입 무료 정책이면 CAC에 반영.

### 1-3. 보조: 건축물대장 (정부 공식 무료)

- [공공데이터포털](https://www.data.go.kr/)의 국토부 건축물대장 API — 동·호수 존재 여부, 전용면적, 준공년도 검증용. 소유자 정보는 없지만 **단지 DB 구축(complexes/units 테이블 시딩)에 활용**.

## 2. 본인확인 (휴대폰 인증)

| 방식 | 제공사 | 비고 |
|---|---|---|
| 휴대폰 본인확인 (PASS/SMS) | **[NICE평가정보 NICE API](https://www.niceinfo.co.kr/business/NICEAPI.nice)**, KCB, SCI | 방통위 지정 본인확인기관. CI/DI 획득 → 계정 유일성 보장 |
| 카카오 인증서 | [카카오](https://www.kakaocorp.com/page/detail/10998) | 카카오 지갑 기반, 전자증명서와 자연 연계 |
| 통합 게이트웨이 | [PortOne 본인인증](https://blog.portone.io/authorization-payment-2/), 이니시스 통합인증 | 여러 인증수단 한 번에 연동, 초기에 유리 |

- **핵심**: 본인확인으로 받는 **CI(연계정보)** 가 "1인 1계정" 및 등기부 소유자 대조의 기준 키가 된다.
- NICE 연동 플로우: 토큰 요청 → 요청 데이터 암호화 → 표준창 호출 → 결과 복호화 (4단계, [연동 예시](https://velog.io/@simhw/Node.js-%EB%82%98%EC%9D%B4%EC%8A%A4-%EB%B3%B8%EC%9D%B8%EC%9D%B8%EC%A6%9D-API-%EA%B5%AC%ED%98%84%ED%95%98%EA%B8%B0)).
- 비용: 건당 수십 원 수준 (계약 조건별 상이).

## 3. 카카오 서류 발급 (기능 3)

### 3-1. 카카오톡 전자증명서 ([digitaldocs.kakao.com](https://digitaldocs.kakao.com/))

- 행안부 **정부24 전자문서지갑**과 연계 — 이용자가 카카오톡 지갑에서 주민등록등본/초본, 건강보험 자격득실, 납세 관련 증명 등 **70종 이상** 공문서를 발급받아 **연계된 기관(제출처)** 에 전자 제출하는 구조 ([카카오 공식](https://www.kakaocorp.com/page/detail/9700), [고객센터](https://cs.kakao.com/helps_html/1073203199?locale=ko)).
- **연동의 실체**: 우리가 "문서를 API로 받아오는" 게 아니라, **우리 플랫폼이 '제출처 기관'으로 등록**되어 이용자가 카톡에서 우리에게 문서를 전자 제출하는 모델. 행안부 전자문서지갑 유통 체계 참여(기관 등록·심사) 또는 카카오 비즈니스 제휴 절차 필요.
- **장점**: 이용자 경험 최상(카톡 안에서 끝), 진본성 검증 가능(위변조 확인).
- **제약**: 제휴/심사 리드타임이 김. 인감증명서 등 일부 서류는 전자 발급 자체가 불가 → 오프라인 안내 병행.

### 3-2. 대안/병행 — 스크래핑 대행 API

| 서류 | 대행 API |
|---|---|
| 주민등록등본/초본 (정부24) | [Tilko](https://tilko.net/), [하이픈 정부24 주민등록](https://hyphen.im/product/view?seq=69) |
| 국세 납세증명 (홈택스) | Tilko, [하이픈 홈택스](https://hyphen.im/product/view?seq=18), CODEF |
| 지방세 납세증명 (위택스) | Tilko, CODEF |
| 신분증 진위확인 | [하이픈 신분증 진위확인](https://hyphen.im/product/view?seq=179) |

- 이용자가 간편인증(카카오/PASS)으로 위임하면 대행사가 해당 기관에서 문서를 조회·수령. 카카오 제휴보다 **훨씬 빨리 시작 가능** → **Phase 2는 Tilko/하이픈으로 시작, 카카오 전자증명서 제휴는 병행 추진** 권장.
- [정부24 공공서비스 Open API](https://www.gov.kr/openapi)는 서비스 목록·안내 위주로, 증명서 발급 자체는 전자문서지갑 체계를 타야 함.

## 4. 세금 계산기용 데이터 (기능 5)

세금 "계산 API"는 신뢰할 만한 외부 제공자가 없음 → **세율·공제 로직은 자체 구현(tax_rules DB)**, 입력 데이터만 외부 조달.

| 데이터 | 출처 | 용도 |
|---|---|---|
| 아파트 매매 실거래가 | [국토부 실거래가 오픈API (공공데이터포털)](https://www.data.go.kr/data/15126469/openapi.do) — 법정동코드 5자리+계약년월로 조회, 무료 | 시세 참고, 희망가 가이드, 매칭 가격 검증 |
| 공동주택 공시가격 | [국토부 공동주택가격정보](https://www.data.go.kr/data/15124003/openapi.do?recommendDataYn=Y) (연 1회 공시, 반기 개방) | 보유세(재산세·종부세) 계산 입력값 자동 채움 |
| 취득세·양도세율 | 법령 기반 자체 DB (지방세법·소득세법) | 개정 시 버전 관리, 세무사 감수 |

- 파이썬 래퍼 [PublicDataReader](https://github.com/WooilJeong/PublicDataReader/blob/main/assets/docs/portal/TransactionPrice.md) 활용하면 프로토타입 속도↑.
- 공공데이터포털 인증키는 신청 후 1~2시간 내 사용 가능, 무료(트래픽 제한 있음, 운영 시 활용신청 등급 상향).

## 5. 알림 — 카카오 알림톡

매칭 제안(48시간 수락 기한) 특성상 도달률 높은 알림톡이 필수.

- 알림톡은 카카오와 계약된 **공식 딜러사를 통해서만** API 연동 가능 ([카카오엔터프라이즈 BizMessage](https://bizmsg-web.kakaoenterprise.com/api-docs/)).
- 딜러사 예: [알리고](https://smartsms.aligo.in/alimapi.html)(저렴, 소규모 친화), [비즈고/인포뱅크](https://blog.bizgo.io/howto/alimtalk-api-integration-guide/), NHN Cloud 등.
- 사전 절차: 카카오 채널 개설 → 비즈니스 채널 심사(1~3영업일) → 딜러사 계약 → **템플릿 사전 검수**(1~3영업일) — 매칭 제안/수락 알림 등 템플릿을 미리 설계·등록해야 함.
- 건당 비용 알림톡 ~7-9원 수준 (SMS 대비 저렴), 실패 시 SMS 폴백 설정 가능.

## 6. 결제·증빙 (기능 7)

| 필요 기능 | 제공사 | 비고 |
|---|---|---|
| PG (카드/이체/가상계좌/정기결제) | 토스페이먼츠, 나이스페이, KG이니시스, PortOne(통합) | 초기엔 PortOne 같은 통합 게이트웨이로 PG 교체 유연성 확보 |
| 현금영수증 자동 발행 | **[팝빌 현금영수증 API](https://www.popbill.com/Content/Link/Cash/API)**, 바로빌 | 국세청 신고까지 처리, 14개 언어 SDK ([개발자센터](https://developers.popbill.com/)) |
| 전자세금계산서 | **[팝빌 세금계산서 API](https://www.popbill.com/Taxinvoice/API)**, 바로빌 | 발행+국세청 전송. 협력업체 월 정산 역발행도 지원 |
| 휴폐업 조회 | 팝빌 부가 API | 협력업체(이사/법무) 온보딩 시 사업자 검증 |

- PG 부가서비스로도 현금영수증 발행이 되는 경우가 있어, PG 선정 시 통합 여부 확인 → 별도 연동을 줄일 수 있음.

## 7. 연동 우선순위 & 비용 요약

| Phase | 연동 | 예상 비용 구조 |
|---|---|---|
| **1 (MVP)** | ① NICE 본인확인 ② CODEF/하이픈 등기부 열람·소유자 검증 ③ 알림톡(알리고) ④ 실거래가·건축물대장(무료) | 인증 1건 ~1,500원, 알림톡 건당 ~9원 |
| **2** | ⑤ Tilko/하이픈 서류 대행 ⑥ 공시가격 API ⑦ (병행 추진) 카카오 전자증명서 제출처 등록 | 서류 조회 건당 수백 원 |
| **3** | ⑧ PG ⑨ 팝빌 현금영수증·세금계산서 | PG 수수료 ~2-3%, 팝빌 건당 수십~백원 |

**공통 리스크**: 스크래핑 기반 API(등기부·정부24·홈택스)는 원천 사이트 개편 시 일시 장애 가능 → ① 대행사 2곳 계약(주/백업), ② 수동 심사 폴백 경로 상시 유지, ③ SLA·장애 보상 조항 계약서 명시.
