## 기능 1. 회원 등록 — "데이팅 앱식 프로필"

### 1-1. 소유주 인증 (특정 단지 소유주만 가입 가능)

**인증 플로우:**

```
휴대폰 본인인증(PASS/카카오)
  → 가입 대상 단지 선택
  → 동·호수 입력
  → 소유주 인증 (아래 3가지 중 택1)
      A. 등기부등본 자동 조회 (인터넷등기소 API/스크래핑) — 성명·생년 대조
      B. 카카오톡 전자증명서 제출 (등기필증/등기부등본)
      C. 수동 심사 (서류 업로드 → 운영자 확인, 영업일 1일)
  → 인증 완료 → 정회원 전환
```

**정책:**
- 1계정 = 1소유 물건 원칙 (다물건 소유자는 물건별 프로필 추가)
- 공동명의: 대표 1인 가입 + 공동명의인 동의 체크 (계약 단계에서 전원 서명 필요 고지)
- 인증 실패/만료: 준회원(열람만 가능) 상태로 제한
- 소유권 변동 감지: 매칭 직전 등기부 재조회로 유효성 재검증

### 1-2. 매수 희망 조건 등록 (이상형 프로필)

| 항목 | 입력 방식 | 비고 |
|---|---|---|
| 희망 단지 | 복수 선택 | 자기 단지 + 인접 단지 |
| 희망 동 | 복수 선택 / 무관 | 동별 시세 차이 반영 |
| 희망 층 | 저/중/고/특정 층 범위 | RR(로얄동·로얄층) 선호도 |
| 희망 평형(타입) | 복수 선택 | 타입코드 기준 (예: 84A, 59B) |
| 희망 향 | 남/남동/남서/무관 | |
| 예산 상한 | 금액 + 대출 계획 | 차액 정산 가능 범위 |
| 우선순위 | 항목별 가중치 슬라이더 | 매칭 점수 계산에 사용 |

### 1-3. 내 집 상태 등록 (내 프로필)

| 항목 | 입력 방식 | 비고 |
|---|---|---|
| 이사 가능 일정 | 날짜 범위 (예: 2026.10 ~ 2027.02) | 사이클 내 일정 교집합 계산 |
| 희망 매도가 | 금액 + 협상 가능 범위 | |
| 인테리어 상태 | 올수리/부분수리/기본/수리필요 + 시공연도 | 사진 필수 |
| 확장 여부 | 발코니 확장 등 | |
| 점유 상태 | 자가 거주 / 전세 / 월세 / 공실 | 임차인 있으면 만기일 입력 |
| 사진/영상 | 최소 5장 | 블러 처리 옵션 (매칭 후 원본 공개) |
| 특이사항 | 누수 이력, 관리비 등 | 고지 의무 항목 체크리스트 |

## 기능 3. 개인 서류 발급 (카카오 전자문서 연동)

**목적**: 계약~잔금 단계에서 필요한 서류를 앱 안에서 발급·제출.

| 서류 | 발급처 | 연동 방식 | 필요 시점 |
|---|---|---|---|
| 등기부등본 | 인터넷등기소 | API/제휴 | 인증·계약 전 |
| 주민등록등본/초본 | 정부24 | 카카오톡 지갑 전자증명서 | 계약·잔금 |
| 인감증명서 | 주민센터 | 안내만 (온라인 발급 불가) | 잔금(소유권이전) |
| 지방세 납세증명 | 위택스 | 전자증명서 | 잔금 |
| 국세 납세증명 | 홈택스 | 전자증명서 | 잔금 |
| 가족관계증명서 | 대법원 | 전자가족관계등록시스템 | 필요시 |

**기능 요구사항:**
- 거래 단계별 "필요 서류 체크리스트" 자동 생성 (매도인/매수인 역할별)
- 카카오톡 전자증명서 제출 → 플랫폼 내 안전 보관함 저장 (암호화, 거래 종료 후 자동 파기)
- 발급 불가 서류는 발급처·준비물 가이드 제공
- 서류 만료일 알림 (등본 등 3개월 유효)

## 기능 4. 협력업체 거래 조건 전달 (숨고 방식)

**목적**: 매칭 확정 시 거래 조건을 협력업체에 자동 전달 → 견적 수신 → 고객이 선택.

### 4-1. 이사업체 연결

전달 데이터: 출발지/도착지(동·호수·층·엘리베이터 유무), 이사일(사이클에서 확정된 날짜), 평형, 짐량 체크리스트, 사다리차 필요 여부

플로우:
```
매칭 확정 → 이사 조건 자동 생성 → 제휴 이사업체 N곳에 견적요청 발송
→ 48시간 내 견적 수신 → 고객 비교·선택 → 예약 확정 → 수수료 정산
```

- **순환거래 특화**: 사이클 참여자 전원의 이사가 같은 날 연쇄적으로 일어남 → "연쇄 이사 시간표" (A가 오전 반출 → B 입주 → B 반출분 C 입주...) 자동 생성, 참여 이사업체 간 시간 조율 기능

### 4-2. 법무법인 연결

전달 데이터: 잔금일, 물건 소재지, 거래가액, 대출 유무(말소/설정), 등기 유형(소유권이전)

- **순환거래 특화**: 사이클 전체의 잔금을 **같은 날 동시 실행**해야 함 → 사이클 단위로 법무법인 1곳이 전체 등기를 총괄하는 "일괄 수임" 옵션 제공 (동시이행 안전장치)
- 견적: 등기 건수 × 수수료 일괄 견적

### 4-3. 확장 (Phase 3+)

인테리어, 입주청소, 에어컨 이전설치 등 동일 패턴으로 확장.

## 기능 5. 세금 계산기 (부동산114 방식)

**목적**: 갈아타기 의사결정의 최대 변수인 세금을 사전 시뮬레이션.

| 세목 | 입력 | 핵심 로직 |
|---|---|---|
| **양도소득세** | 취득가·취득일·양도가·보유기간·거주기간·주택수·조정지역 여부 | 1주택 비과세(12억), 장기보유특별공제, 일시적 2주택 특례 |
| **취득세** | 취득가·주택수·전용면적·조정지역 여부 | 1~12% 구간, 생애최초 감면 |
| **보유세** | 공시가격·주택수·1주택 단독명의 여부 | 재산세 + 종부세, 공정시장가액비율 |
| **중개보수** | 거래가액 | 요율 상한 자동 계산 |

**차별화 — "갈아타기 통합 시뮬레이션":**
- 매도세금 + 매수세금 + 부대비용을 한 화면에서 합산 → **"이 갈아타기의 총비용"** 산출
- 매칭된 사이클 기준으로 자동 프리필 (내 매도가·매수가·잔금일이 이미 확정되어 있으므로)
- 일시적 2주택 특례 기한(신규 취득 후 3년 내 종전주택 처분) 캘린더 알림
- 세법 개정 대응: 세율표를 DB화하여 시행일 기준 버전 관리
- 면책 고지: "본 계산은 모의계산이며 세무사 상담 필요" 명시

## 기능 6. 고객 및 거래 관리 CRM

**사용자**: 내부 운영팀 + 협력 중개사

### 파이프라인 (거래 상태 머신)

```
리드 → 가입/인증 → 프로필 완성 → 매칭 대기 → 매칭 제안
→ 상호 수락 → 협의 중 → 가계약 → 본계약 → 중도금 → 잔금/등기 → 이사 완료 → 사후관리
```

**기능:**
- 고객 360° 뷰: 인증 상태, 물건 정보, 선호 조건, 매칭 이력, 상담 기록, 서류 현황
- 사이클 단위 거래 보드: 순환거래 1건 = 참여자 N명의 계약 N건을 하나의 딜로 묶어 관리
- 일정 자동화: 계약일·중도금일·잔금일·이사일 → 참여자 전원 + 협력업체 캘린더 동기화, 리마인드 발송
- 이탈 감지: 프로필 미완성 3일, 매칭 제안 미응답 48시간 등 트리거 → 알림/아웃바운드 태스크 생성
- 상담 채널 통합: 카카오 채널/전화 상담 기록 첨부

## 기능 7. 결제 시스템

### 7-1. 결제

| 결제 대상 | 결제자 | 방식 |
|---|---|---|
| 매칭 성사 수수료 | 사이클 참여자 각자 | PG (카드/계좌이체/가상계좌) |
| 프리미엄 멤버십 | 회원 | 정기결제 |
| 협력업체 리드 수수료 | 업체 | 후정산 (월 단위) |

- PG 연동: 토스페이먼츠/나이스페이 등 1개사로 시작
- 에스크로적 안전장치: 매칭 수수료는 **잔금 완료 확인 후 확정** (그 전엔 카드 가승인 또는 보증금 방식) — 거래 무산 시 자동 환불 정책 명문화
- **주의**: 매매대금 자체는 플랫폼을 거치지 않음 (전금법 리스크 회피, 당사자 간 직접 이체 + 법무사 입회)

### 7-2. 세금계산서 / 현금영수증 자동 발행

- 수수료 결제 완료 시: 개인 → 현금영수증, 사업자 → 전자세금계산서 자동 발행
- 국세청 전자세금계산서 API 또는 PG 부가서비스 활용
- 협력업체 월 정산 시 역발행 세금계산서 플로우 지원

## 기능 8. 거래 보고서

**목적**: 거래 종료 시 참여자에게 "이 거래의 전체 기록"을 문서로 제공. 신뢰·바이럴 포인트.

**보고서 구성 (PDF + 웹뷰):**
1. 거래 요약: 사이클 구조도(누가 어디로 이사했는지), 거래가액, 주요 일정 타임라인
2. 비용 정산 내역: 매도/매수가, 차액 정산, 수수료, 법무비, 이사비
3. 세금 리포트: 납부한 취득세, 예상 양도세, 향후 보유세 전망, 일시적 2주택 처분기한 알림
4. 서류 보관함: 계약서·영수증·등기완료 서류 아카이브 (다운로드)
5. 사후 안내: 전입신고, 자금조달계획서, 실거래 신고 확인 등 체크리스트

**운영용 보고서 (내부/중개사):**
- 월별 매칭 성사율, 사이클 길이 분포, 평균 리드타임, 단지별 수요/공급 히트맵
