# 01. 서비스 개요 — 부동산 순환거래 매칭 플랫폼

## 1. 한 줄 정의

> **"같은 단지 안에서 갈아타고 싶은 소유주들을 데이팅 앱처럼 매칭하고, 순환거래(사이클)로 동시에 거래를 성사시키는 플랫폼"**

## 2. 문제 정의 (Why)

한국 부동산 갈아타기의 구조적 문제:

1. **동시성 딜레마**: 집을 팔아야 살 수 있고, 사야 팔 수 있다. 매도·매수 타이밍이 어긋나면 일시적 2주택(세금 폭탄) 또는 전세 난민이 된다.
2. **정보 비대칭**: 같은 단지 안에 "내 집을 원하는 사람"과 "내가 원하는 집의 주인"이 존재해도 서로를 발견할 방법이 없다. 중개사는 개별 매물 단위로만 움직인다.
3. **거래 비용**: 이사·법무·세금 처리가 각각 분절되어 있어 갈아타기 1회에 수십 시간의 탐색 비용이 든다.

## 3. 해결 방식 (How)

- 단지 소유주만 가입하는 **폐쇄형 커뮤니티** (신뢰 기반)
- 소유주의 "내 집 정보"와 "원하는 집 조건"을 **방향 그래프**로 모델링
- **TTC(Top Trading Cycles) 알고리즘**으로 2자~N자 순환거래 사이클을 탐색
- 매칭 성사 시 **서류 발급 → 협력업체 연결 → 세금 계산 → 결제 → 거래 보고서**까지 원스톱 처리

### 데이팅 앱 메타포

| 데이팅 앱 | 본 서비스 |
|---|---|
| 프로필 등록 | 내 집(동·호수·컨디션) 등록 |
| 이상형 조건 | 매수 희망 타입(동·층·향·평형) |
| 상호 좋아요 → 매칭 | 선호 그래프 사이클 → 순환거래 매칭 |
| 만남 주선 | 잔금일·이사일 조율 + 계약 지원 |

## 4. 타겟 고객

- **1차**: 대단지 아파트(1,000세대 이상) 내 평형·동·층 갈아타기 수요자
  - 예: 소형→중대형 (가족 증가), 저층→고층, 구축동→신축동
- **2차**: 인접 단지 간 갈아타기 (같은 생활권)
- **B2B**: 단지 협력 중개사무소, 이사업체, 법무법인, 인테리어 업체

## 5. 비즈니스 모델

| 수익원 | 방식 | 시점 |
|---|---|---|
| 매칭 성사 수수료 | 거래가액 대비 정률 또는 정액 (중개보수 대비 할인) | 잔금 완료 시 |
| 협력업체 리드 수수료 | 이사·법무·인테리어 견적 연결 건당 | 견적 성사 시 |
| 프리미엄 멤버십 | 매칭 우선 노출, 세금 시뮬레이션 무제한 | 월 구독 |
| B2B CRM 라이선스 | 협력 중개사무소용 거래관리 툴 | 월 구독 |

## 6. 벤치마크 레퍼런스

| 기능 영역 | 벤치마크 | 차용 포인트 |
|---|---|---|
| 회원/매칭 UX | 데이팅 앱 (틴더, 아만다) | 프로필·선호 등록, 상호 매칭 알림 |
| 서류 발급 | 카카오톡 전자문서/지갑 | 등기부등본·주민등록초본 등 간편 발급 |
| 협력업체 연결 | 숨고 | 조건 전달 → 견적 수신 → 선택 |
| 세금 계산 | 부동산114 세금계산기 | 양도세·취득세·보유세 시뮬레이션 |
| 거래 관리 | 중개사무소 CRM | 고객·매물·거래 파이프라인 |

## 7. 법적 고려사항 (초기 검토 필요)

- **공인중개사법**: 매칭 후 실제 계약은 등록 중개사를 통해야 함 → 협력 중개사 모델 필수 (플랫폼은 "정보 제공 + 중개사 연결" 포지션)
- **개인정보보호법**: 소유주 인증 과정의 등기부·신분증 정보 처리 → 수집 최소화, 인증 후 파기
- **전자금융거래법**: 결제 대행은 PG사 연동으로 해결
- **부동산거래신고법**: 실거래 신고는 중개사/법무사 몫이나, 플랫폼이 일정 관리 지원
