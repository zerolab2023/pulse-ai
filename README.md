# pulse-ai — 부동산 순환거래 매칭 플랫폼

> 같은 단지 안에서 갈아타고 싶은 소유주들을 데이팅 앱처럼 매칭하고,
> TTC(Top Trading Cycles) 알고리즘 기반 순환거래로 동시에 거래를 성사시키는 플랫폼.

## 핵심 기능 (8)

1. **회원 등록** — 단지 소유주 인증(등기부/카카오 전자증명서), 매수 희망 타입·이사 일정·인테리어 상태 등록
2. **매칭** — 그래프 이론 + 사이클 탐색 + TTC 알고리즘, 매물 컨디션 가중치
3. **개인 서류 발급** — 카카오톡 전자증명서 연동
4. **협력업체 연결** — 이사업체(이사일정), 법무법인(잔금일정) 견적 전달
5. **세금 계산기** — 양도세·보유세·취득세 통합 시뮬레이션
6. **CRM** — 고객·딜 파이프라인 관리
7. **결제** — 수수료 결제 + 세금계산서/현금영수증 자동 발행
8. **거래 보고서** — 사이클 구조도, 비용 정산, 세금 리포트 PDF
