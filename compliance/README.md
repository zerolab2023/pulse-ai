# 컴플라이언스 게이트 (의료광고법 1차 필터)

콘텐츠 파이프라인에서 **성능보다 우선하는 하드 제약(fail-closed)**. 글이 발행되기 전
위험 표현(치료경험담·치료효과 오인·과장·환자유인 등)을 잡아 **차단하고 대체 문구를 제안**한다.

> 설계 배경은 [`docs/marketing-agent-design.md`](../docs/marketing-agent-design.md) 3장 참고.
> ⚠️ 이 검사는 **1차 필터**다. 의료광고 **사전심의·의료인 감수를 대체하지 않는다.**

## 왜 이게 가장 먼저인가

건강검진·내과 블로그는 "완치", "최고", 후기 한 줄로 의료법 제56조 위반이 될 수 있고
**책임은 병원(의료인)에게 귀속**된다. 글을 잘 쓰는 것보다 **사고를 막는 브레이크**가 먼저다.

## 사용

```bash
# 파일 검사
python3 -m compliance.run --file draft.md

# 파이프로 검사
echo "안양 최고의 병원 완치 후기 이벤트" | python3 -m compliance.run

# 기계 판독용 JSON (콘텐츠 생성기 → 게이트 자동 연동)
python3 -m compliance.run --file draft.md --json
```

## 판정 (decision)

| 판정 | 의미 | 종료코드 |
|---|---|---|
| 🛑 **BLOCK** | block 규칙 1건 이상 → **발행 불가**, 수정/감수 필요 | `2` |
| 🟡 **REVIEW** | warn 규칙만 → 검토 후 발행 | `0` |
| 🟢 **PASS** | 위험 표현 없음(그래도 최종 감수는 필요) | `0` |

종료코드 `2`(BLOCK)를 CI/자동화에서 발행 차단 트리거로 쓴다.

## 잡아내는 유형 (룰셋 v1, `rules.py`)

| 유형 | 심각도 | 예시 |
|---|---|---|
| 치료경험담/후기 | 🛑 차단 | "후기", "치료경험담", "다녀왔어요" |
| 치료효과 오인/과장 | 🛑 차단 | "완치", "부작용 없음", "100%", "보장" |
| 최상급/비교광고 | 🛑 차단 | "최고", "유일", "1위", "국내 최초" |
| 환자 유인/할인 | 🟡 검토 | "이벤트", "무료 검진", "선착순", "할인" |
| 자격/인증 과장 | 🟡 검토 | "명의", "정부 공인", "대한민국 대표" |
| 비의료인 의학적 단정 | 🟡 검토 | "반드시 수술", "무조건 검사", "꼭 받아야" |

각 매칭마다 **왜 위험한지(근거) + 어떻게 바꿀지(대안)**를 함께 출력한다.

## 파이프라인 위치

```
콘텐츠 생성기 → [컴플라이언스 게이트] → (BLOCK면 리라이트 루프) → 의료인 감수 → 발행
                       │
                       └ BLOCK: 발행 차단 + 대체문구로 재생성 요청
```

## 확장 (다음 단계)

- 룰셋은 룰베이스(빠르고 결정론적) **1차 필터**. 맥락 판단이 필요한 경우
  LLM 심사(2차)를 붙여 "후기처럼 안 보이지만 유도성" 문장까지 잡는다.
- 룰은 `rules.py`에 `Rule(...)` 한 줄 추가로 확장. 지역·진료과별 사전 분리 가능.

## 모듈 구성

- `rules.py` — 위험 표현 룰셋(정규식 + 근거 + 대체문구)
- `checker.py` — 텍스트 검사 + fail-closed 판정
- `run.py` — CLI (파일/표준입력, 사람용·JSON 출력)

의존성: 파이썬 3.10+ 표준 라이브러리만.
