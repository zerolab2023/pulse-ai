# web/ — P0 클릭 프로토타입

`index.html` 하나로 동작하는 **의존성 0** 모바일 웹 프로토타입. 브라우저로 열면 바로 실행된다.

```bash
# 로컬 실행
python3 -m http.server 8000 --directory web
# → http://localhost:8000
```

## 왜 Next.js가 아닌가

현재 원격 개발 환경의 네트워크 정책이 npm 레지스트리(및 모든 CDN)를 차단하고 있어 패키지 설치가 불가능하다.
그래서 P0 화면 전체를 순수 HTML/CSS/JS로 먼저 구현했다. 화면·상태 구조는 [docs/07 프론트엔드 기획서](../docs/07-frontend-plan.md)와 1:1 대응하므로, npm 사용이 가능한 환경에서 Next.js(App Router)로 포팅할 때 라우트/컴포넌트 경계를 그대로 옮기면 된다.

## 구현 범위 (P0)

| 라우트 | 화면 | 비고 |
|---|---|---|
| `#/` | 랜딩 | 단지 수요 카운터, 순환거래 3컷 설명 |
| `#/onboarding` | 가입 4단계 | 본인인증→동·호수→등기부 대조(시뮬레이션)→완료 |
| `#/home` | 매칭 대시보드 | 상태별 4가지 뷰 (미완성/대기/제안/거래중) |
| `#/profile/my-home` | 내 집 프로필 | 완성률 게이지, 사진·컨디션·일정 |
| `#/profile/wishlist` | 매수 희망 조건 | 동·타입 칩, 가중치 순위, 잠재 상대 피드백 |
| `#/matches/1` | 매칭 제안 상세 | SVG 사이클 다이어그램, 48h 카운트다운, 점수 분해, 정산표 |
| `#/deal/1` | 딜 룸 | 타임라인, 할 일, 참여자 |
| `#/calculator` | 세금 계산기 | 취득세 간이 로직 구현 (모의계산 고지) |
| `#/notifications` `#/my` | 알림·마이 | |

## 프로토타입 장치

- 우상단 `demo:` 셀렉터 — 홈 화면 상태를 강제 전환 (스테이크홀더 데모용)
- 모든 입력은 `localStorage`(`djm` 키)에 저장 — "프로토타입 초기화"는 마이 탭에서
- 본인인증·등기부 조회·사진 업로드는 시뮬레이션 (실연동은 docs/06 참조)
